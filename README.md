# MatryoshkaAudit / Regulator Service

Ситуационный центр и нормативно-аналитический бэкенд платформы **MatryoshkaAudit** для регуляторов (Минпромторг РФ, ТПП РФ, ФСТЭК).

## Ключевой функционал
1. **Нормативный аудит по ПП РФ № 719**:
   - Автоматический подсчёт баллов по технологическим операциям.
   - Оценка адвалорной доли добавленной стоимости.
   - Детекция разрыва между "бумажной" и "де-факто" локализацией.
2. **Симулятор санкционных шоков**:
   - Моделирование каскадного отказа при блокировке транзита через нейтральные юрисдикции.
   - Оценка вероятности останова конвейера по теории О-Ринга (Kremer, 1993).
3. **ИИ-модель геополитических сценариев (OpenRouter Pipeline)**:
   - Анализ новых пакетов санкций ЕС/G7 и их каскадного воздействия на микроэлектронику и гидравлику.
   - Генерация предписаний и компенсационных мер поддержки.
4. **Выдача цифровых заключений Минпромторга**:
   - Криптографический хэш SHA-256 и ссылка для QR-верификации в ГИСП.
